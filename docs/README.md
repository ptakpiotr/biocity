# BioCity documentation

## Architecture decision records

The ADRs follow Michael Nygard's format: title, status, context, decision, and consequences. They document decisions made during application development and their current implementation. Each ADR lists its status near the top. The repository had no existing ADR numbering scheme, so descriptive filenames are used without introducing an artificial sequence.
